# Testing Practice 2

A small Spring Boot Java project used for practicing application testing with controller, repository, and validation coverage.

## Stack
- Java 25
- Spring Boot 4.1.1
- Maven
- Spring Data JPA
- H2 database for tests

## Project structure
- `src/main/java/com/vaishu/testing` — application code
- `src/main/resources` — configuration and app resources
- `src/test/java/com/vaishu/testing` — test classes

## Run locally
```bash
./mvnw spring-boot:run
```

## Run tests
```bash
./mvnw test
```

This app is a simple practice project for testing Spring Boot components and user-related functionality.
